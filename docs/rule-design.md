# Rule Design

- `MIN_REQUIRED`: 不满足则实验结论为 `BLOCKED`
- `RECOMMENDED`: 不阻断，只给推荐补充
- 前置实验：可跳过，但输出强提醒并降低置信度
- 规则匹配升级为结构化方式：
- `TAG_ANY`：按试剂用途标签匹配，如 `WB_LYSIS_BUFFER`、`QPCR_MASTER_MIX`、`FIXATIVE`
- `ANTIBODY_TARGET_ANY`：按抗体靶点匹配，可附带 `PRIMARY/SECONDARY` 角色约束
- `PRIMER_TARGET_ANY`：按引物靶点匹配
- `PRIMER_REFERENCE`：按内参引物匹配
- `NAME_ANY`：仅保留给历史兼容和兜底关键词
- 基础实验知识：
- `WB` 最低必需：裂解/样本制备、上样缓冲液、目标一抗、二抗、检测底物、至少一个内参抗体
- `qPCR` 最低必需：RNA 提取、逆转录、qPCR 扩增体系、目标引物、至少一个内参引物、无核酸酶水
- `IF` 最低必需：固定液、透化试剂、封闭液、目标一抗、荧光二抗、核染、封片/抗淬灭介质
- `ELISA` 最低必需：包被相关试剂、封闭液、洗板缓冲液、检测抗体、显色底物
- `FLOW` 最低必需：荧光抗体、染色缓冲液；活死染与 marker 一抗为推荐项
- 新增细粒度标签已接入推荐层规则：
- `WB`：转印膜、蛋白定量试剂、还原剂、磷酸酶抑制剂
- `qPCR`：细胞培养基、血清添加物
- `IF`：细胞骨架染料、细胞器染料、细胞培养基、血清添加物
- `AUTOPHAGY/SECRETORY_AUTOPHAGY`：转染/基因递送试剂
- `EXOSOME`：外泌体分离试剂、细胞培养基、血清添加物
- 手动输入实验名称时，系统先尝试归一到正式实验类型；若匹配度不足，则返回候选实验模板，并要求人工确认，不自动写入正式目录
- 方向规则：
- 自噬/分泌性自噬：`WB` 强制 `LC3 + p62`，`qPCR/IF` 提供相关 marker 推荐
- 外泌体 `WB`：至少 1 个 tetraspanin（`CD9/CD63/CD81`）+ 至少 1 个 `TSG101/ALIX`；`Calnexin` 为推荐污染排查项
- 常见自配缓冲液默认优先作为推荐项，避免库存未登记导致误阻断
